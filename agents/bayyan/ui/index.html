The method

Three things, never blurred

A verse is literature, not a fatwa and not tafsir. Bayyan keeps these registers apart on purpose.

a

What the words say

The literal sense: text, transliteration, glossary, grammar and imagery.

b

What the poet meant

The literary reading — marked probable, with alternatives where the line is ambiguous.

c

What the tradition says

Quran and hadith on the theme, cited as surah:ayah and verified before use — or omitted honestly.

Install

Ready in two commands

Copy the agent into your OpenCode agents folder. OpenCode reloads it automatically.

Windows PowerShell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.config\opencode\agents" | Out-Null
Copy-Item agents\bayyan\opencode.md "$env:USERPROFILE\.config\opencode\agents\bayyan.md"
opencode agent list | Select-String bayyan
macOS / Linux
mkdir -p ~/.config/opencode/agents
cp agents/bayyan/opencode.md ~/.config/opencode/agents/bayyan.md
opencode agent list | grep bayyan

Then: opencode --agent bayyan · or ask your main agent: “Use the bayyan subagent on this verse…”
